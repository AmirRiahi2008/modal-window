# modal-window
## 🎯 Overview

**Modal Window App** is a simple and elegant web application built with **HTML**, **CSS**, and **JavaScript**.  
It allows users to open and close modal windows using dedicated buttons. Each button opens a specific modal, which can be closed by clicking either the **Close button** or the **Overlay** area outside the modal.

This app features a clean and responsive UI, perfect for learning or showcasing modal functionality in modern web development.

---

## ✨ Features

- 🪄 **Open and close modals** with smooth transitions
- 🖱️ **Close modals** via overlay click or dedicated **Close (`×`) button**
- 🎨 **Minimal and responsive UI design**
- 🧩 Each button opens **its own unique modal**
- ♿ Improved **accessibility** and UX

---

## 🛠️ Technologies Used

- 🔹 **HTML5**
- 🔸 **CSS3**
- ⚡ **Vanilla JavaScript (ES6)**
